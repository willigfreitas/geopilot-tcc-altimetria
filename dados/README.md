# Dados do experimento

## Dados utilizados

- duas rotas urbanas de São José dos Campos (SP);
- MDE SRTM com resolução nominal de 30 m;
- SRC de cálculo: SIRGAS 2000 / UTM zona 23S — EPSG:31983.

## Política de publicação

O raster completo não é incluído devido ao tamanho e à necessidade de preservar a rastreabilidade da fonte. O repositório deverá informar a origem, o identificador do produto, a data de acesso e o recorte utilizado.

Antes da publicação dos arquivos vetoriais, devem ser conferidos:

- licença e atribuição da fonte de roteamento;
- ausência de chaves de API e metadados sensíveis;
- sistema de referência e nomes das camadas;
- correspondência com as geometrias efetivamente utilizadas no artigo.
